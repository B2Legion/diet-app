# Diet Plan App

A mobile-first Progressive Web App (PWA) for a **pure vegetarian nutritional recovery meal plan** — designed to combat hair loss, fatigue, and frequent headaches while addressing Vitamin B12 and D3 deficiencies.

All meal options are optimised for online food delivery (Zomato / Swiggy).

## Features

- **7-day rotating meal plan** — Monday through Sunday, each day with a theme
- **3 meals + snacks per day** — Breakfast, Lunch, Dinner, and daily snack suggestions
- **Fat Loss filter** — toggle to show only calorie-conscious options, hiding heavier recovery meals and treats
- **Meal tags** — every option is labelled Fat Loss, Recovery, or Treat so you always know what you're picking
- **Auto day detection** — opens on today's day automatically
- **Daily reminders** — B12 supplement and hydration tips built in
- **Installable on iPhone** — add to Home Screen from Safari and it runs fullscreen like a native app

## Tech Stack

- [Next.js 16](https://nextjs.org) (App Router)
- [Tailwind CSS v4](https://tailwindcss.com)
- PWA via [@ducanh2912/next-pwa](https://github.com/DuCanhGH/next-pwa)

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Installing on iPhone

1. Open the deployed URL in **Safari**
2. Tap the **Share** button
3. Tap **Add to Home Screen**
4. It will open fullscreen like a native app
